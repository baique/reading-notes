# Reading Notes

Reading Notes 是一个 Obsidian 桌面插件，把网页阅读、问题记录、AI 解答和 Markdown 笔记放在同一个 `.read` 文件中。

> 仅支持 Obsidian 桌面端。

## 功能

- 在 Obsidian 中内嵌打开文章网页。
- 为每篇文章记录多个问题。
- 录入问题后自动查询 AI 解答，也可以在设置中关闭自动查询。
- AI 解答支持 Markdown 渲染。
- 针对已有解答继续追问，追问结果保存在原问题下方。
- 查看查询状态：等待、正在解答、已完成或失败。
- 查询失败可以直接重试。
- 为每个问题填写自己的答案，失焦后自动保存。
- 使用 Markdown 编辑器记录整篇文章的笔记。
- 网页、问题和笔记区域都可以调整布局比例。

## 安装

### 从 Community Plugins 安装

在 Obsidian 中打开：

1. 设置 → 第三方插件；
2. 关闭安全模式；
3. 浏览并搜索 `Reading Notes`；
4. 安装并启用。

### 手动安装

从 [Releases](https://github.com/baique/reading-notes/releases) 下载以下文件，并放入 Vault 的：

```text
.obsidian/plugins/reading-notes/
```

需要下载：

```text
main.js
manifest.json
styles.css
```

## 使用

### 新建阅读

- 在文件浏览器中右键文件夹，选择“新建阅读”；或
- 使用命令面板执行“新建在读（标题 + 链接）”。

输入文章链接后，插件会尝试自动获取网页标题。

### 记录问题

在右侧问题输入框中输入问题，点击“记下”，也可以使用 `⌘/Ctrl + Enter` 提交。

如果启用了“自动查询 AI 解答”，插件会立即开始查询。查询完成后，AI 解答会自动出现在问题下方。

### 继续追问

在问题卡片的“继续追问”区域输入问题并提交。追问会参考原文章、原问题、原 AI 解答和当前 Markdown 笔记。

### 记录个人答案

在“你的答案”区域输入自己的理解。输入框失焦后，内容会自动保存到 `.read` 文件。

### 编辑笔记

底部区域是 Markdown 源码编辑器，支持标题、加粗、引用、代码、链接、撤销和软换行。笔记会自动保存。

## AI 配置

打开设置 → Reading Notes：

| 设置 | 说明 |
| --- | --- |
| 自动查询 AI 解答 | 开启后，提交问题会自动查询；关闭后需要手动点击“立即解答” |
| 取答案的命令 | 外部命令，stdout 会作为 AI 解答 |
| 提示词模板 | 支持 `${link}`、`${title}`、`${question}`、`${notes}` |
| 命令超时 | 单次查询的最大等待时间，单位为毫秒 |

默认命令：

```text
pi --no-session -p "${prompt}"
```

外部命令必须包含 `${prompt}`，并将最终解答输出到 stdout。

## 隐私说明

插件不会单独上传或收集数据。启用 AI 查询后，文章链接、文章标题、问题和部分 Markdown 笔记会按照提示词模板传给你配置的外部命令；实际数据处理方式取决于该命令及其使用的 AI 服务。

关闭“自动查询 AI 解答”后，插件不会自动执行 AI 查询。

## 文件格式

每篇阅读内容保存为一个 `.read` 文件，包含文章信息、问题、AI 解答、追问、个人答案和 Markdown 笔记。该文件由插件读取和写入，不建议使用普通 Markdown 视图直接编辑。

## 限制

- 仅支持 Obsidian 桌面端；
- 部分网站禁止被 iframe 或 webview 嵌入；
- AI 查询依赖本机已安装并可执行的外部命令；
- AI 查询速度和结果取决于外部命令及其配置。

## 开发

```bash
pnpm install
pnpm build
```

开发时可以将项目目录软链接到 Vault：

```text
<Vault>/.obsidian/plugins/reading-notes
```
