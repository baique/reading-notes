# Reading Notes

Obsidian 插件：把「一篇在读写笔记」做成一种**文件类型** `.read`，双击就用阅读视图打开——像 canvas 那样。

## 形态

- 文件：`<任意目录>/<标题>.read`，内容是结构化 JSON。放哪儿由你决定，插件全库扫描
- 视图：上面是**原文预览（`<webview>`）+ 问题栏**，下面是一条**内嵌 CodeMirror 的 markdown 笔记区**，两根分隔线都能拖（指针捕获，拖过网页也不丢事件），比例存进设置
- 笔记存在 `.read` 里，不额外建文件；编辑器是 markdown 源码模式：标题/加粗/引用/代码/链接都有着色，撤销、缩进、软换行齐全
- 双击 `.read` 即进入阅读视图；文件浏览器、标签页、置顶、恢复会话都和普通文件一致

```json
{
	"title": "某某文章",
	"url": "https://example.com/post",
	"created": "2026-02-14",
	"notes": "# 笔记\n\n- 这里就是笔记区的正文",
	"questions": [
		{
			"id": "m1abc2",
			"text": "为什么 A 会 B？",
			"answer": "AI 给的参考答案",
			"answerAt": "02-14 15:03",
			"mine": "我自己的回答"
		}
	]
}
```

- `answer` 是 AI 的参考区，`mine` 是你的回答，互不覆盖
- 笔记是 `.read` 里的 `notes` 字段，纯 markdown；查答案时它会作为 `${notes}` 变量（前 2000 字）

## 用法

1. 在文件浏览器里**右键任意文件夹 → 新建阅读**，文件就建在这个目录下（根目录右键也行）；也可以用命令 `新建在读`，默认落在当前文件所在目录
2. 弹窗里**先粘链接**，插件自动抓网页标题填进标题框；标题框留空也能照抓
3. 右上问题栏记问题，`⌘/Ctrl + Enter` 或点「记下」存下
4. 8 秒内后台开始查（之后每 5 分钟扫一次），答案直接写回文件，「查询中…」原地变成参考答案
5. 查失败会在问题下显示**可读的原因**（超时 / 命令没找到 / stderr 原文 / 退出码）和「重试」；自动轮询最多试 3 次，手动点「重试 / 现在查」不受限制
6. 问题行悬停出现「改 / 删」：改是就地编辑，删要点两下确认
5. 参考下面是「你的答案」，自己写一遍，失焦即存
8. 下面的笔记区直接用，600ms 自动存回 `.read`

## 安装

```bash
pnpm install
pnpm build
```

把 `main.js`、`manifest.json`、`styles.css` 放进 vault 的 `.obsidian/plugins/reading-notes/`，启用即可。开发时整个目录软链过去，`pnpm dev` 持续编译。

## 配置

| 项 | 说明 |
| --- | --- |
| 后台静默查答案 | 关掉就只手动触发 |
| 取答案的命令 | 在 shell 里执行，**stdout 全文就是答案**，按 markdown 渲染。默认 `pi -n --prompt "${prompt}"` |
| 提示词模板 | 支持 `${link}` `${title}` `${question}` `${notes}`；渲染结果替换命令里的 `${prompt}` |
| 命令超时 | 默认 180000ms，超时只放弃这一条 |

## 入口

- 文件浏览器右键文件夹 → `新建阅读`
- 命令 `新建在读（标题 + 链接）`
- `打开在读内容`
- `立即补齐待答问题`（手动补一轮）

## 已知边界

- 仅桌面端：依赖 Electron `<webview>`，移动端没有
- 标题点开可改，文件名保持不变
- 界面刻意不画框：分区靠留白与字号；输入框聚焦只有一条底部细线；拖动分隔条时才浮出一根发丝线
- PATH：GUI 启动的 Obsidian 只有 `/usr/bin:/bin` 一类的 PATH，而 nvm/homebrew 通常写在 `~/.zshrc` 里，`zsh -lc` 读不到。插件启动时用 `zsh -ilc 'printf %s "$PATH"'` 问一次交互式登录 shell，缓存后注入子进程 env，所以 `pi` 这类 nvm 命令能找到
- 拖动分隔条：按下时读取当前位置作为基准，每帧只落一次布局，拖动期间冻结 webview/编辑器的指针交互
- 命令里的 `${prompt}` 会按双引号字符串转义（`$` `` ` `` `"` `\` 都安全），所以写成 `"${prompt}"` 即可
- 早期版本留下的同名 `.md` 笔记文件，打开 `.read` 时会自动并回 JSON 并删掉那个文件（避免重命名打乱已有的链接与双链）
- 文件内容是 JSON，别用 Markdown 视图改它；想批量处理直接编辑 JSON 也行
- 早期版本把笔记存成一整段字符串，读入时会自动转成一条随记，不丢内容
